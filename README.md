# CUT! CUT! BOOM!

流れてくるダイナマイトの、言われた色の線を切るゲーム。1本でも間違えたら終わり。

- 左の線: A / ←、右の線: D / →（画面のボタン、スマホは画面の左右タップでも可）
- Esc / P で一時停止
- EASY は線に色の名前あり、HARD はなし

色名は JIS Z 8102:2001 の慣用色名。HEX は Wikipedia「JIS慣用色名」（oldid=111583927）の参考値に固定し、画面の線はこの HEX のまま表示します。

three.js r128 を使っています。ビルドは不要で、そのまま静的ファイルとして配信できます。
